Field note 5 · Real evidence, 2026-11-21

What the lab actually proved, and what each number means

P3 NIM smoke test on an AKS GPU node pool, plus P2 AI-Q lessons. Interviewers probe numbers, so know the “why” behind each one.
P3 · NIM on one A100 80 GB (Spot)
30B-A3B
Mixture-of-experts

30B total parameters, ~3B active per token. It computes like a 3B model but needs memory like a 30B one. Active parameters ≠ resident weights.

75 GB
VRAM used of 80

Not the model size. vLLM pre-allocates most free VRAM for the KV cache. High VRAM use doesn't mean the model is huge.

99%
GPU utilization, 246 W

nvidia-smi “util” = % of time any kernel ran, not how busy the SMs were. Use DCGM SM-activity and Nsight to see real saturation.

0.67–0.82 s
3 concurrent requests

Non-streaming, thinking off. This is not TTFT. TTFT/ITL need a streaming path measured with AIPerf (P2/P4).

INT4 · TP1
Profile vllm-int4-tp1-pp1

Tensor parallel 1 and pipeline parallel 1, so the whole model fits on one GPU. NIM chose vLLM here, not TRT-LLM.

Marlin
Weight-only kernels

A100 (Ampere) has no native FP8/FP4 tensor cores. Hopper adds FP8 and Blackwell adds FP4. On A100, low-precision weights are dequantized in the kernel.

~3 min
Start to /health/ready

Plus a 10.8 GB image pull (3m16s) and a ~21 GB model cache on emptyDir. NIMCache on a PVC is the fix for fast restarts.

0 keys
Identity path

NGC key: Key Vault → private endpoint → CSI driver → K8s secret. App: workload identity → Foundry + Search with no keys.

P2 · Things that went wrong (your best interview stories)

The 429 storm

One AI-Q deep report made 49 model calls and 20 throttled retries. The first run made 340+ calls before it was cancelled. Azure counts each request's max_tokens against TPM.
So: agentic fan-out is a capacity problem. Use a dedicated 400K-TPM deployment and enforce a per-report call budget.

The blueprint got it wrong

AI-Q missed the pharmacy fax change and returned the general prior-auth fax instead. Its source list also collapsed to one page per file. The simple keyword baseline got it right.
So: a blueprint is a starting point, not proof of correctness. Independent golden answers caught it.

Static key vs. Entra

AI-Q's nim provider only accepts a static API key. Policy forbids Foundry keys.
So: a loopback-only sidecar swaps in a refreshed Entra token from workload identity. It's an enterprise-security pattern you can reuse.

Thinking ate the budget

Hidden reasoning used all 8,192 output tokens and the request failed with length.
So: set enable_thinking=false for strict-JSON tasks. Reasoning tokens cost latency and money.

Empty agent answer

A shallow run hit max_tool_iterations: 5 and returned nothing. AI-Q doesn't force a final answer.
So: raise the limit to 8 and treat an empty answer as a failure, never as success.

Capacity is not a quota

East US 2 had no free Search capacity. PostgreSQL B1ms wasn't available. Spot A100s can be evicted at any time.
So: check physical allocation at execution time. One Spot GPU is a lab, not HA.
Rule: a running pod or a healthy endpoint is not evidence. Evidence is logs + GPU activity during a real request + a passing quality check.

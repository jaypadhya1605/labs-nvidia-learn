NIMis packaging: the box you ship
Tritonis serving: the door requests come through
TensorRT-LLMis the engine: where tokens are made
CUDAis the runtime: how code reaches the GPU
Say it like this: “When a customer says ‘we run NIM,’ my first question is which profile and which engine. On our A100, NIM picked a vLLM INT4 profile, so a NIM-vs-vLLM test would mostly measure packaging. Only a separate TRT-LLM lane actually tests the engine.”
